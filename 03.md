# term type and kind
### term
- a term is a syntax element that represents a unit of computation or value. Term is inhabit types and can be evaluated or reduced via reduction rules (such as $\beta$-reduction).
- if a term $t$ has type $T$ under a typing context $\Gamma$, it is denoted as:

$$\Gamma \vdash t: T$$

### type
- a type is a static predicate that has classifies terms and bounds their allowable operations. It defines the set of values a term can evaluate to and ensures static safety.
- Grammar Example (Simply Typed Lambda Calculus)

$$T ::= B|T_1 \rightarrow T_2$$

*(where $B$ represents base types and $T_1 \rightarrow T_2$ represents function types)*

### kind
- a kind is tye type of type. in languages featuring type constructors, generics or *Higher-Kind Types(HTKs)*, kinds are used by the compiler to check the **well-formedness** of type-level expressions
> well-formedness: In linguistics, well-formedness is the quality of a clause, word, or other linguistic element that conforms to the grammar of the language of which it is a part

- if a type expression $T$ has kind $K$ under a type context $\Delta$, it is denoted as:
$$\Delta\vdash T::K$$

- standard Kind Grammar
1. **Proper Kind($\star$ or $\text{Type}$):** the kind of all fully applied, concrete types that classify terms (e.g., $\text{Int}::\star, \text{Bool}::\star$)
2. **Operator Kind($K_1\Rightarrow K_2$):** the kind of type constructors that map a type of kind $k_1$ to a type of kind $K_2$ (e.g.,$\text{List}::\star\Rightarrow\star$)

### The Three-Level Hierarchy
- in system $F_\omega$, the relationship is structured as follows:
$$\text{Term} \quad \xrightarrow{\quad : \quad} \quad \text{Type} \quad \xrightarrow{\quad :: \quad} \quad \text{Kind}$$

1. **Term Level:**
$$\lambda x:\text{Int}.x+1 \quad: \quad \text{Int} \rightarrow \text{Int}$$
*an executable function expression (Term) whose type is $\text{Int} \rightarrow \text{Int}$*

2. **Type Level (Level 1):**
$$\text{List} \quad :: \quad \star \Rightarrow \star$$
*A type constructor (Type) that takes a concrete type (like $\text{Int}$) and yields a new concrete type ($\text{List Int} :: \star$).*

3. **Kind Level (Level 2):**
$$⋆⇒⋆$$
*A meta-type (Kind) that describes the arity and structural shape of type-level functions.*
